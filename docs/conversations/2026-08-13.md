## 主题：进销存看板品项筛选（单选 + 数据联动）

### 需求

「进销存看板」标题下方新增**品项筛选**，单选，默认「全部」，可选：电解质水 / 气泡水 / 冰茶 / 维生素水 / 好自在 / 其他。

### 实现

#### 1. 筛选 UI

- 胶囊（pill）按钮组，单选，默认「全部」高亮
- 样式：`.item-filter-row` / `.item-pill`，选中态蓝底白字（`#3b82f6`）
- 与页面现有季度选择器风格协调

#### 2. 数据联动

- 进销存数据从静态 HTML 重构为 JS 数据驱动（`renderPss(item)`）
- 切换品项后，3 张卡片 + 履约明细（月表+季表）/ 分销明细 / 库存明细同步刷新

**缩放规则**：

| 指标类型 | 处理方式 |
|----------|----------|
| 量值类（金额/箱数/网点数/批发商数/分销商数/万元目标实际） | 按品项系数缩放（`Math.round(v × factor)`） |
| 比率类（达成率/同比/占比/绿牌占比/差异率/VPO/天数） | 保持「全部」值不变 |

**品项系数（原型模拟）**：

| 品项 | 系数 |
|------|------|
| 全部 | 1.00 |
| 电解质水 | 0.35 |
| 气泡水 | 0.22 |
| 冰茶 | 0.15 |
| 维生素水 | 0.12 |
| 好自在 | 0.10 |
| 其他 | 0.06 |

### 实现要点

- 用 `querySelector('#detail-fulfill .card')` 等定位现有 DOM 节点，通过 `outerHTML` 替换，避免大面积改静态 HTML
- `.pss-grid` 用 `innerHTML` 重渲染 3 张卡片
- 比率类字段不缩放，保证各品项下达成率/占比等视觉稳定

## 主题：驾驶舱重构（改名 + 明细表列重构 + 四分位色灯）

### 需求

1. 页面标题「渠道经营驾驶舱」→「经销商经营驾驶舱」
2. 总表：移除「满分标准」列，实际分值前加色灯
3. 明细表表头重命名 + 列结构调整
4. 色灯按四分位分档

### 实现

#### 1. 改名

- 页面 `<h1>` 与 `<title>` 改为「经销商经营驾驶舱」

#### 2. 总表

- 移除「满分标准」列（表头 + 汇总行 + 细项行）
- 「实际分值」前加色灯（汇总行总分 + 7 项指标分）

#### 3. 明细表列重构

| 原 | 新 |
|---|---|
| 履约情况（5列：合同额梯队） | YTM履约情况（4列：履约达标率分布占比） |
| 分销情况 | 分销渠道占比（自营/直销网点/批发商/分销商/其他） |
| 库存 | 库存情况（绿牌占比） |
| 窜货（次数梯队） | 窜货及低价次数（线上/线下一级/线下二级/低价） |
| 预付款资金 | 月初预付款情况（经销商合格率） |
| 专职人员 | 专职人员情况（合格率） |
| 利润情况 | 子列重排：当月回顾毛利率/当月回顾净利润/YTM回顾毛利率/YTM回顾净利率 |

#### 4. 色灯规则（四分位）

- top25%绿、25-50%黄、50-75%橙、75%以上红
- 基于全国整棵树所有节点，每列独立计算
- 加点位置：总表实际分值（总分+各指标）、明细表≥100%经销商占比/自营/经销商合格率
