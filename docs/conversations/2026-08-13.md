# 2026-08-13 会话记录

## 主题：进销存看板品项筛选（单选 + 数据联动）

### 需求

「进销存看板」标题下方新增**品项筛选**，单选，默认「全部」，可选：电解质水 / 气泡水 / 冰茶 / 维生素水 / 好自在 / 其他。

### 实现

#### 1. 筛选 UI

- 胶囊（pill）按钮组，单选，默认「全部」高亮
- 样式：`.item-filter-row` / `.item-pill`，选中态蓝底白字（`#3b82f6`）
- 与页面现有季度选择器风格协调

#### 2. 数据联动

- 进销存数据从静态 HTML 重构为 JS 数据驱动（`renderPss(item)`）
- 切换品项后，3 张卡片 + 履约明细（月表+季表）/ 分销明细 / 库存明细同步刷新

**缩放规则**：

| 指标类型 | 处理方式 |
|----------|----------|
| 量值类（金额/箱数/网点数/批发商数/分销商数/万元目标实际） | 按品项系数缩放（`Math.round(v × factor)`） |
| 比率类（达成率/同比/占比/绿牌占比/差异率/VPO/天数） | 保持「全部」值不变 |

**品项系数（原型模拟）**：

| 品项 | 系数 |
|------|------|
| 全部 | 1.00 |
| 电解质水 | 0.35 |
| 气泡水 | 0.22 |
| 冰茶 | 0.15 |
| 维生素水 | 0.12 |
| 好自在 | 0.10 |
| 其他 | 0.06 |

### 实现要点

- 用 `querySelector('#detail-fulfill .card')` 等定位现有 DOM 节点，通过 `outerHTML` 替换，避免大面积改静态 HTML
- `.pss-grid` 用 `innerHTML` 重渲染 3 张卡片
- 比率类字段不缩放，保证各品项下达成率/占比等视觉稳定
