> **版本**：v1.1  
> **日期**：2026-08-06  
> **状态**：持续迭代

---

## 1. 功能概述

本项目包含两个 Demo：

### 1.1 经销商数据看板（静态原型）
面向单经销商的经营数据驾驶舱，以可视化方式呈现经销商核心评估指标。
- **用户角色**：经销商负责人 / 区域经理
- **使用场景**：查看经销商基础信息、按季度查看评估等级与各维度得分

### 1.2 渠道经营驾驶舱（React 应用）
面向渠道运营的多级数据下钻分析平台。
- **用户角色**：渠道运营经理 / 战区负责人
- **使用场景**：从全国到分部的多级下钻，总表考核评估 + 明细表全维度数据
- **技术栈**：React 19 + TypeScript + Vite 6 + Tailwind CSS 4
- **核心功能**：
  - 4 级下钻（全国 → 战区 → 作战部 → 作战分部），全国始终展开
  - 总表：7 大维度考核细项，支持展开/折叠，部门列 rowSpan 合并
  - 明细表：基础情况/履约/分销/库存/窜货/预付款/专职人员/利润
  - 自定义满分标准展示

### 3.6 ECharts 雷达图 — 左图（4 大维度）

| 属性 | 规格 |
|------|------|
| 维度（轴序） | 合规经营(↑)、业绩表现(←)、执行能力(↓)、自身能力(→) |
| 轴排列方向 | **逆时针**（ECharts 默认行为） |
| 最大值 | 各维度目标值（100/50/100/200） |
| 实际值（Mock） | 73/40/50/60 |
| 系列1（实际） | 蓝色 `#3b82f6`，填充 `rgba(59,130,246,0.15)`，线宽 2px |
| 系列2（目标） | 灰色 `#6b7280`，无填充，线宽 2.5px |

| 自定义 tooltip | 8 区域角度判定，4 行：名称 / 目标 / 实际 / 达成率 |

**8 区域悬浮逻辑**：4 轴分菱形为 4 三角，每三角对半劈 = 8 个 45° 扇形。
- `atan2(dy, dx)` 计算鼠标角度
- 角度数组 `[-90, 180, 90, 0]`（逆时针匹配 ECharts 轴位）
- 最近轴判定 → 显示对应指标数据

## 4. 数据流

### 4.1 数据模型

```
QuarterData {
  grade: 'D' | 'C' | 'B' | 'A'      // 评估等级
  score: number                       // 得分 (18-92)
  percentile: string                  // 分位值描述
  radar: number[4]                    // 4大维度平均值
  targetRadar: [100, 100, 100, 100]  // 目标值（固定100）
  details: Indicator[15]             // 15项分项详情
  targetDetails: Indicator[15]       // 分项目标（固定100）
}

Indicator {
  name: string    // 指标名称
  cat: string     // 所属维度
  val: number     // 实际值 (18-85)
}
```

### 4.2 数据来源

| 阶段 | 来源 | 说明 |
|------|------|------|
| 原型 | 前端随机生成 | `rand(18, 85)` 模拟，按季度预分配等级分布 |
| 正式 | 后端 API | 待对接真实数据源 |

### 4.3 等级分布（原型模拟）

```
2026F1 → D, 2026F2 → D, 2026F3 → D, 2026F4 → C
2027F1 → C, 2027F2 → B, 2027F3 → B, 2027F4 → A
```

各等级得分区间：
- D: 18–32
- C: 33–50
- B: 51–70
- A: 71–92

### 4.4 交互流

```
用户切换季度
  → QuarterSelect.onChange(q)
  → updatePanel(q)
      → 更新 GradeBadge（文字 + 样式类）
      → 更新 MetricCards（等级/得分/分位值 + 颜色）
      → renderRadar(data)       ← 左雷达图刷新
      → renderDetailRadar(data) ← 右雷达图刷新
```

## 5. 验收标准

### 5.1 基础信息展示

- **Given** 页面加载完成
- **When** 查看顶部信息区
- **Then** 5 个信息卡片完整显示，时钟每秒更新

### 5.2 季度切换

- **Given** 默认选中 2026F1（等级 D，红色）
- **When** 用户切换到 2027F4
- **Then** 等级徽章变为 A（蓝色），得分和分位值同步更新，两张雷达图数据刷新

### 5.3 Tab 切换

- **Given** 默认显示"整体"Tab
- **When** 用户点击"明细结果"Tab
- **Then** 显示明细占位区域，雷达图隐藏
- **When** 用户切回"整体"Tab
- **Then** 雷达图正常显示且尺寸正确

### 5.4 响应式

- **Given** 浏览器窗口宽度 ≤ 1100px
- **When** 查看雷达图区域
- **Then** 两张图上下堆叠（单列）

## 6. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 雷达图容器隐藏时 resize | Tab 切换到雷达图后延迟 50ms 调用 `.resize()` |
| 极端得分（接近 0 或 100） | 雷达图 max=100，值域被包含 |
| 快速切换季度 | 每次切换全量刷新，ECharts 自动处理动画打断 |
| 窗口 resize | 监听 `window.resize`，同步 resize 两张雷达图 |
