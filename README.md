## 项目概述

面向经销商的经营数据驾驶舱，以可视化方式呈现核心业务指标。

## 功能概览

### 已完成（原型）

| 模块 | 说明 |
|------|------|
| 经销商基础信息 | 5 列卡片：开户时间、主营城市、授权区域、客户类型、渠道类型 |
| 季度选择器 | 2026F1 ~ 2027F4，联动评估数据 |
| 评估等级体系 | D/C/B/A 四档，含颜色徽章、得分、分位值 |
| 4 维度雷达图 | 合规经营 / 业绩表现 / 执行能力 / 自身能力 |
| 15 项分项雷达图 | 按维度着色标签，目标线 100 |
| Tab 切换 | 整体评估 ↔ 明细结果 |
